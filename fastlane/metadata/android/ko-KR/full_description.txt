FT8AF는 안드로이드 휴대폰이나 태블릿을 그대로 완전한 FT8 운용국으로 바꿔 줍니다. 무전기를 USB로 연결하고 CQ를 누르면, 컴퓨터 없이 전 세계와 교신할 수 있습니다.

밴드에 들어오는 모든 신호를 실시간으로 디코딩하고, 표준 FT8 메시지를 송신하며, 교신은 자동으로 기록됩니다. 산 정상에서의 이동 운용이든, 필드데이 운용이든, 집에서 간단히 즐기는 운용이든 필요한 것은 모두 주머니 속에 있습니다.

준비물
• 데이터 단자 또는 USB 단자가 있는 HF 무전기
• USB OTG 케이블 또는 USB 오디오 인터페이스
• 안드로이드 6.0 이상의 휴대폰이나 태블릿

지원 무전기
USB CAT 제어를 통해 야에수, 아이컴, 켄우드, Elecraft 등 대부분의 HF 트랜시버와 함께 동작합니다. FlexRadio, Icom IP, Xiegu X6100 같은 네트워크 무전기도 지원합니다. 제어 방식은 CAT, VOX, RTS, DTR을 지원합니다.

디코딩과 송신
• 빠른 모드와 딥 모드를 갖춘 실시간 FT8 디코딩
• 실시간 워터폴과 스펙트럼 표시, 터치로 주파수 지정
• CQ 호출, 특정 국 호출, 자유 문자 메시지
• 송신 슬롯 선택, TX 워치독, 자동 감시
• 호출국 대기열이 있어 가장 센 신호를 좇는 대신 진행 중인 교신에 집중할 수 있습니다
• 자동 추적으로 교신하고 싶은 국을 지켜봅니다

로그북
• 교신이 끝나면 자동으로 기록됩니다
• DXCC, CQ 존, ITU 존 집계
• 밴드별·거리별 통계
• ADIF 파일 가져오기 및 내보내기
• 로그 항목 수정 및 삭제

로그 서비스 연동
• Cloudlog, Wavelog, QRZ.com, Nextlog로 교신 업로드
• 교신마다 동기화 상태가 표시되어 무엇이 올라갔는지 알 수 있습니다
• 설정에서 연결 테스트로 계정 정보를 확인할 수 있습니다

지도와 PSK Reporter
• 교신 상대의 위치를 보여 주는 인터랙티브 지도
• PSK Reporter 레이어로 내 신호가 세계 어디에서 수신되는지 확인
• 디코딩된 모든 국의 그리드 로케이터와 거리 표시

오디오와 연결
• USB 오디오 장치와 블루투스 오디오 지원
• 샘플링 레이트와 비트 심도 설정 가능
• USB를 연결하면 무전기에 자동으로 접속

운용자를 위해 만들었습니다
FT8AF는 BG7YOZ의 FT8CN을 현대적으로 다시 만든 포크로, 최신 Compose UI와 17개 언어 현지화, 수십 가지 새 기능과 버그 수정을 담았습니다. K1AF와 N0rC가 햄벤션으로 향하는 I-70 도로 위에서 시속 70마일로 달리며 개발했습니다.
